# GTO Poker Trainer

Phase 1 scaffold. Install Node.js and pnpm, then run `pnpm install` and `pnpm dev` from this directory. Copy `.env.example` to `.env.local` and add an Anthropic API key for model-powered features; the key is optional for startup. The Bible is read from `BIBLE_DIR` and is not modified. Local runtime files are written under `data/`.
